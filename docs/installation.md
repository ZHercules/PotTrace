# PotTrace 安装与使用

0.1.0 开发版适用于 Windows 11 x64 和 64 位 PotPlayer。已验证的组合为 1.7.22859.0（EVR、现有 UTF-16 LE INI）和 1.7.23172.0（内置 D3D11、当前用户注册表）。新版注册表安装会校验播放器 EXE 和核心 DLL，并保留现有渲染器。首次安装要求注册表中尚无私有外部滤镜列表。发行包内含 .NET 运行时。

## 快速安装与卸载

解压完整 ZIP，退出 PotPlayer 和 PotTrace，双击 **快速安装.cmd**。选择要安装的 `PotPlayerMini64.exe`，然后在 PotPlayer 的 F5 → 扩展功能 → 播放统计中勾选 PotTrace。

安装后，**Ctrl+Alt+Shift+H** 通过 Windows 开始菜单快捷方式启动统计界面，已有窗口会被唤起。播放器后台运行期间也可以使用应用快捷键，默认为 **Ctrl+Alt+H**，可在统计设置里修改。遇到热键占用时，可从开始菜单打开「PotTrace 播放统计」。

卸载时退出两个程序，双击同一解压目录中的 **快速卸载.cmd** 并选择原播放器。卸载会移除插件、程序文件、登记的快捷方式和 PotTrace 的私有滤镜登记，保留统计历史和设置。首次打开统计窗口，在设置中勾选“启用播放统计”，选择“详细”可从新会话开始保存片段。

## 命令行安装

1. 解压完整发行包；退出要安装到的 PotPlayer 和已运行的 PotTrace。
2. 在发行目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -PotPlayerPath 'E:\pot\PotPlayer'
```

3. 打开 PotPlayer，在 **选项（F5）→ 扩展功能 → 播放统计** 中勾选 **PotTrace**。这是首次启用的一次性步骤。
4. 打开影片，使用程序目录中的“播放统计”快捷方式或托盘入口查看状态。出现当前影片名称，并在停留超过 10 秒后出现有效会话，才表示采集已工作。单纯“已连接”不能证明播放统计扩展已经勾选。

以后后台由 PotPlayer 扩展自动启动，统计窗口无需每次打开。不注册 Windows 开机启动项。安装器不修改视频、不改用户目录权限、不复制原播放器的观看历史。升级只替换登记为 PotTrace 自有的文件，并保留设置和数据库。

默认程序目录：`%LocalAppData%\Programs\PotTrace`；默认数据目录：`%LocalAppData%\PotTrace`。安装脚本支持显式 `-InstallRoot`、`-DataRoot` 参数。数据库应放本机磁盘。

## 统计口径

- 当前影片播放或暂停的停留时间严格超过 10 秒才计为一次打开，之前的可靠播放时间会追认。仅在队列中的影片不计入。
- 累计播放时长采用真实经过时间；暂停不增加播放时长，重复观看重复累计。
- 详细片段必须连续实际播放严格超过 5 秒。暂停、跳转、缓冲及通信缺口会截断片段。连续变速保留同一片段，单独记录变速事件；估计速度及采样观测窗口随 JSON 明细导出。短片段仍计入有效会话总时长，但不进入热度。
- 影片汇总按完整文件名归并，包含扩展名、忽略大小写；不同来源以及文件替换版本的热度分开。
- “精简 / 详细”按钮仅切换查看方式。设置中的采集模式从下一会话生效；旧精简记录不会补出虚构明细。
- 日期筛选按会话打开日期选择完整会话；跨日的实际时长另存按日事实。

## 运行与隐私

关闭统计窗口会隐藏到托盘并继续记录。托盘的“退出 PotTrace”会停止本轮播放器的自动重启；手动启动 PotTrace 或重新打开播放器可以恢复连接。“暂停统计”是持久化设置，重启不会自动解除。

所有记录保存在本机，不上传。可以设置排除目录，按当前筛选删除所选影片记录，导出 CSV/JSON，或通过 SQLite 备份接口备份。删除当前会话后，本次打开期间不再补记该会话，避免旧事件重试使记录复活。

恢复备份会暂停采集，并保留独立的 `pottrace.db.before-restore-<唯一编号>`，重复恢复不会覆盖先前的安全副本。结构不完整或损坏的备份会被拒绝。遇到损坏数据库不会自动删除重建；请保留原文件和诊断日志再处理。

## 精度与兼容性

本版采用播放回调加位置/状态采样。目标版本的位置查询约每 500 毫秒刷新，并非逐帧精度；没有可靠的公开倍速读取接口，速度由连续观察估算。极短的往返跳转可能不可观察。

隔离测试播放器曾出现 1.7–8 秒的初始回调延迟，正常显示启动也观察到约 2 秒的偶发延迟。因此本版是开发预览，打开后立即暂停并停留约 11 秒的边界尚不能保证每次及时计入。初始无法可靠识别媒体的时间不会虚构补齐。完整实测结果和未验证项目见仓库的验收记录及发行包中的 `验收记录.md`，不能将某一个场景的误差推广到所有操作。

截图中的 WebView2 目录错误来自隔离测试环境尝试访问默认数据目录。测试脚本已使用项目内专用的 `WEBVIEW2_USER_DATA_FOLDER`，不会修改用户目录 ACL；正式统计窗口使用 WPF，不依赖 WebView2。

## 卸载

退出目标播放器及 PotTrace，然后执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Uninstall.ps1 -PotPlayerPath 'E:\pot\PotPlayer'
```

默认保留历史与设置。只有明确添加 `-RemoveHistory` 才删除登记数据目录中的已知统计文件。卸载不递归删除播放器目录或用户数据目录。
