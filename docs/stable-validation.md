# 正式采集器开发验收

2026-11-18，本轮实现稳定版计划任务 1–3 的首个增量：正式 AX 自动加载、首次启用、启停控制和有界生命周期。基线 `a51a4fa`，分支 `codex/stable-collector`，在独立 worktree 开发；主工作区既存修改未覆盖。**仍是开发预览，没有部署到 `E:\pot\PotPlayer`。**

任务 1 的独立计时见证校准、任务 3 的第三方阻塞实播及长时资源证明尚未完成；不能把本报告理解为任务 1–3 所有验收项或完整稳定版验收已通过。

## 实现与回归覆盖

- 新建 `PotTrace.Collector.ax`，私有 CLSID，提取原型来源/渲染器复合观测；无需脚本影片回调或 `POTTRACE_*` 测试环境变量。Bridge 与策略读取在后台启动，视频透传回调不做磁盘或外部图遍历。
- `capture-policy.json` 为正式模式的授权依据。文件缺失/损坏即不采集；首次设置可创建授权；原生允许删除共享，宿主串行递增版本并使用原子替换。覆盖 30 次并发修改及 100 次读取、原生 500 次替换。
- 插件真实勾选状态同时检查 `ExtensionSection` 和 `ExtensionInfoList` 的 `DN` 标志；修复取消勾选未通知 `OnFinalize` 时仍在采集的问题。主动退出宿主抑制本播放器实例再启动；再次启动播放器按已保存授权自动运行。
- 四个固定查询线程、一个管理线程、最多两个图；旧查询返回后受 generation 与授权边界检查。槽位未接纳不分配编号，避免编号空洞。独立终止邮箱处理关闭，普通采样队列满或旧查询阻塞不延后旧绑定截止。
- 可控阻塞工作项证明：Retire 不等待查询、旧结果不得发布、另一组槽可记录新影片、解除阻塞后槽归零。该测试模拟查询阻塞，不等于在真实播放器内注入第三方永久挂起 COM 的验证。
- 默认关闭的固定大小健康文件不含影片路径。仍未实现完整的用户可见故障/缺口状态、跨版本协议握手及稳定数据库迁移。
